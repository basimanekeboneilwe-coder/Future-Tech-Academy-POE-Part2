# Future Tech Academy Website

## Project Overview

Future Tech Academy is a responsive educational website designed to provide information about technology education and training programmes.

The website introduces the academy, displays available programmes, provides course information and pricing, allows visitors to make an enquiry, and provides contact information.

## Purpose of the Website

The purpose of the website is to:

- Introduce Future Tech Academy.
- Provide information about the academy.
- Display available technology programmes.
- Provide course descriptions, age groups, durations and prices.
- Allow visitors to submit an enquiry.
- Provide contact details for the academy.

## Target Audience

The website is aimed at:

- Young learners.
- Students interested in technology.
- Parents and guardians.
- People interested in coding and digital skills.

## Website Pages

### Home

The Home page introduces Future Tech Academy and provides a short description of the academy's focus on coding, technology and digital skills.

It also includes a button linking visitors to the Programs page.

### About Us

The About Us page provides information about:

- The history of Future Tech Academy.
- The academy's mission.
- The academy's vision.

### Programs

The Programs page displays three technology programmes:

**Junior Coders**
- Level: Beginner
- Age Group: 10-14 years
- Duration: 8 Weeks (Saturdays)
- Price: R 1,200

**Web Development Fundamentals**
- Level: Intermediate
- Age Group: 15-18 years / Adults
- Duration: 12 Weeks
- Price: R 2,500

**Python & Data Analytics**
- Level: Advanced
- Age Group: 16-25 years / Adults
- Duration: 10 Weeks
- Price: R 3,000

Each programme includes an Enquire Now button linking to the Enquiry page.

### Enquiry

The Enquiry page provides a form that allows visitors to submit information and enquire about a programme.

The form includes fields for:

- Full Name
- Email Address
- Contact Number
- Student Age
- Preferred Programme

The form uses required fields and appropriate input types.

### Contact Us

The Contact Us page provides the academy's contact information:

- Email: info@futuretechacademy.org
- Phone: +27 (0)12 567 890
- Address: 123 Innovation high, Tech Hub, South Africa

## Responsive Design

The website is designed to work on different screen sizes.

Responsive CSS media queries are used for:

Desktop screens.
Tablet screens.
Mobile screens.

On smaller screens, the navigation changes to a vertical layout and programme/content cards adjust to fit the available screen width.

The programme cards display in a single column on small mobile screens.
